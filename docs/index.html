Why Pure Native Rust?

Designed from scratch for competitive Dota 2 players who care about speed, privacy, and zero background bloat.

🦀 Memory-Safe Native Code

Compiled directly to x86_64 machine code with eframe / egui OpenGL rendering — no Chromium, Node.js, or Edge WebView2 required.

☁️ Cloud-Safe Sync

Copies only allowlisted Dota 2 key/convar files, verifies SHA-1 parity, and leaves remotecache.vdf untouched so Steam Cloud uploads your fresh binds.

🛡️ Automated Backups

Snapshots your target account's allowlisted Dota 2 settings automatically before syncing or restoring, keeping up to 10 snapshots per account with 1-click restore from inside the app.

🔒 100% Local & Auditable

No telemetry, no password prompts, and full public Rust source code in Mightyiest/Switcheroo.
